# Automated Parking Management System — Software Engineering Design

**Academic software engineering project | The Hebrew University of Jerusalem**

**Project format:** Exercises 1–4 were completed by a five-person team. The final guest-access extension was designed individually by Tzachi Elya.

## Overview

A structured software engineering **design and planning** project for a proposed automated parking management system. The work documents the system's functional requirements, business rules, architecture, component interfaces, software testing strategy, and integration stages.

The proposed system coordinates entry/exit stations, payment stations, signage, a central management computer and a database. It addresses parking capacity, vehicle identification, payment, fault handling, safety and availability.

**Scope note:** These deliverables are software engineering designs and test plans; they do not demonstrate deployment of a functioning physical parking system or independently establish that implementation code was written.

## Individual final project: Guest access for subscribers

Independently specified a feature allowing parking subscribers to invite guests in advance within an approved quota. Key planned capabilities and constraints included:

- Guest reservation and cancellation flows and permission/quota changes.
- Defined reservation windows, advance booking and cancellation rules.
- Guest billing, credit-card processing considerations and monthly charge breakdowns.
- High-level requirements for users and external stations, and changes to existing applications, interfaces and data structures.
- Work Breakdown Structure (WBS), architecture/process documentation, example test scenarios and an implementation task list.
